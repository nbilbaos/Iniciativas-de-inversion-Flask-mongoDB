Información sobre la exportación

La exportación incluirá todas las colecciones definidas en la base de datos, incluyendo sus metadatos (estructura) y los datos almacenados en cada una.

Detalles del formato seleccionado:
  • Exporta toda la base de datos en un solo archivo
  • Mantiene la estructura y relaciones entre colecciones
  • Ideal para respaldos completos del sistema
  • Fácil de importar nuevamente al sistema
  • Genera un archivo CSV separado por cada colección
  • Ideal para análisis de datos en Excel u otras herramientas
  • Fácil de compartir con usuarios externos al sistema
  • No incluye metadatos de estructura de colecciones
Recomendaciones
  • Respaldos regulares: Se recomienda exportar la base de datos regularmente como respaldo.
  • Documentación: Guarda una copia de la estructura de la base de datos para referencia.
  • Seguridad: Almacena los archivos exportados en un lugar seguro.
  • Formato JSON: Utiliza este formato para respaldos completos del sistema.
  • Formato CSV: Ideal para análisis de datos o cuando necesites compartir información con otros usuarios.
